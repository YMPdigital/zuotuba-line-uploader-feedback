# 做圖吧 LINE 貼圖上架工具

這裡提供操作協助、問題回報與功能建議。

遇到問題時，請先搜尋[既有工單](https://github.com/YMPdigital/zuotuba-line-uploader-feedback/issues)；若沒有相同問題，請[建立新工單](https://github.com/YMPdigital/zuotuba-line-uploader-feedback/issues/new/choose)，說明工具版本、操作步驟、預期與實際結果。

GitHub 工單是公開內容。貼上截圖或診斷紀錄前，請遮蔽購買信箱、授權碼、LINE 登入資訊、電腦使用者名稱、商品頁帳號識別碼與尚未公開的作品。
